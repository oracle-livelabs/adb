# Lab 1 Facilitator Guide

## Introduction

Prepare and recover the Product Recall Assistant Lab 1 environment with the companion runbook.

Estimated Time: 20 minutes

### Objectives

- Prepare the relational recall schema and Lab 4 model prerequisites.
- Bootstrap separate owner and runtime identities.
- Confirm all Lab 1 checkpoints.
- Reset learner environments.

## Task 1: Prepare Lab 1

1. Follow [the Lab 1 facilitator runbook](lab1-runbook.md).

2. Run the `ADMIN` bootstrap once, then disconnect `ADMIN`.

3. Reconnect as `RECALL_OWNER` and run the owner setup, environment check, solution, and reset scripts.
