# Shared workshop assets

Estimated Time: Reference only; not a timed learner task.

### Objectives

Locate approved shared assets and their provenance for workshop reuse.

This folder holds approved, reusable workshop diagrams and screenshots. Each
learner lab keeps its step-specific screenshots in its own `images/` folder.
See [traceability.md](../documentation/traceability.md) for the capture queue and publication
rules.

Lab 1 includes LiveLabs Reservation Information examples. Its Environment
Details image is a password-redacted illustration, not a live credential source.
Participants always use their own reservation's values.

[event-lab-values.md](event-lab-values.md) contains public endpoints and the
names of the source credentials already created during provisioning. Actual
source passwords, SAS tokens, and Databricks OAuth values stay in the private
provisioning workflow, never this repository or Starter Kit. The older
private-values template redirects readers to this reference.
