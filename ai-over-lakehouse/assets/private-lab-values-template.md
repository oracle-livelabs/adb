# PeakGear event values — compatibility link

Estimated Time: Reference only; not a timed learner task.

### Objectives

Locate the canonical connection reference and distinguish provisioned source credentials from database login values.

Use [event-lab-values.md](event-lab-values.md) for public endpoints and the
provisioned source credential names. LiveLabs already creates
DBX_PEAKGEAR_OAUTH and ADLS_PEAKGEAR_DATA for the participant. Learners select
these credentials instead of entering source passwords or OAuth values. If
either name is missing, stop and ask the instructor. No protected values are
distributed in this file.

Use Database User and Database Password from your own LiveLabs Reservation
Information → Environment Details. Lab 3, Task 1 explains how to obtain the
assigned database's MCP URL with a read-only SQL query. This compatibility
file keeps older links working.
